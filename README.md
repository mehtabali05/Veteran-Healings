# Veteran Healings

An eCommerce platform built to support veterans by providing wellness-focused products and a donation flow that helps raise funds for suicide prevention initiatives.

The platform enables users to browse and purchase products intended to support emotional well-being and recovery-oriented care, while also allowing direct donations to a suicide prevention organization.

## Project Purpose

Veteran Healings was built to combine eCommerce functionality with a mission-driven donation flow. The goal of the platform is to make it easier for veterans to access wellness-oriented products while also giving users a direct way to support suicide prevention efforts through donations.

* **Frontend:** React.js, TypeScript
* **Backend:** NestJS, Node.js
* **Database:** PostgreSQL, MongoDB
* **ORM:** Drizzle ORM
* **Data Fetching:** TanStack Query
* **Authentication:** Better Auth
* **Media Storage:** Cloudinary
* **Email Services:** SendGrid, Brevo
* **Deployment:** Vercel, Railway, Neon DB
* **Payments:** Stripe

## Setup

```bash
git clone https://github.com/your-username/veteran-healings.git
cd veteran-healings
npm install
npm run dev
```

## Environment Variables

Create a `.env` file and configure the required values for your setup.

```bash
DATABASE_URL=
JWT_SECRET=
NEXT_PUBLIC_APP_URL=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
SENDGRID_API_KEY=
BREVO_API_KEY=
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
```

> Update these variables based on the services used in your implementation.
